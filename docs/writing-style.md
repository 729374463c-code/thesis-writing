# 自然准确的学术中文

## 基准
以作者本人认可的修改稿为主要基准，观察自然段长度、句式节奏、术语密度、来源转述和比较方式。目标是保留个人表达和学术准确性，不刻意制造口语、错误或随机同义词。

## 七类问题及处理
| 问题 | 判断方法 | 改法 |
|---|---|---|
| 空泛评价 | 删掉“重要、深刻、丰富”等词后是否还有具体信息 | 写出对象、关系、变化或问题 |
| 作者名单 | 是否每句都只是“某某研究了……” | 按观点分歧、研究方法或证据组织 |
| 无内容的参照 | “提供依据”后是否说明采用哪个判断 | 写出概念内容及其分析用途 |
| 机械衔接 | 每段是否都以“由此可见、综上所述”结束 | 直接写新增判断；无新增则删 |
| 过度防御 | 限定是否约束紧邻的具体结论 | 保留有效范围，移走核查过程和重复解释 |
| 抽象名词堆叠 | 能否指出谁做了什么、材料如何变化 | 用主体、动作、条件和结果重写 |
| 重复纠偏 | 是否连续使用“不是……而是……” | 正面说明机制，必要处才保留对比 |

## 自拟例子
以下例子只示范写法，不代表真实研究结论。

空泛句：“该变化具有重要价值，为后续研究提供了新的思路。”
可用写法：“该变化把分析重点从单个符号转向符号之间的排列关系。”后文仍须给出材料与来源。

工作记录句：“目前尚未核实相关材料，因此这一部分不能得出结论。”
处理方式：私人记录保存缺口；正文只在必要处明确研究对象与范围。不要换成一个未经证实的肯定句。

无用途引用：“某研究提出了这一概念，对本文具有参考价值。”
可用写法：“该概念区分了形式识别与意义解释，本文据此分别考察材料的可见特征及其语境关系。”实际使用时必须确认这确为来源观点。

## 逐段清稿
先标注一段的唯一任务，再检查每句是否有贡献。合并重复解释，删除对协作者的指示、检索状态和占位语。核对代词、概念和因果连接是否清楚。最后回到证据：删改后有没有把可能性写成事实、把个案写成普遍规律、把设计意图写成实现效果。

不一律删除否定句或限定语，也不靠缩短句子、换生僻词来获得所谓“人味”。术语应稳定，引用、数字和研究发现不得因润色而被改动。自然表达不等于降低学术严谨性。
