# 范文结构与语言学习

## 读什么、怎样读
使用自己拥有或已获授权的材料。在私人工作区记录出处与阅读范围。文本提取适合目录和内容检索；页码、注释区、图表及字号需要渲染观察。分别记录PDF物理页和印刷页，不能默认两者相同。全文文字阅读、逐页缩略图检查和局部放大检查要分别表述。

## 结构拆解的六个层面
1. 总体结构：摘要、绪论、主文、结语、书目等分别承担什么功能。
2. 章节推进：研究对象如何界定，问题如何分类，案例如何证明，结语回收哪些发现。
3. 章节内部：章首段如何承接前文，各节是否解决不同问题。
4. 段落功能：提出判断、比较定义、交代材料、分析关系、提出异议或作局部结论。
5. 引证位置：引用支持的是定义、史实、方法、比较还是反证；作者在引文之后补了哪些推理。
6. 可见版式：层级、目录收录、注码、页下注、分隔线、页码和书目分别观察。

不要把同样的章数当作学会结构。类型研究、单个作品分析、实证调查所需材料不同，不能把范文的方法和结论直接移植。

## 用语分析
建立私人前后对照样本：作者删掉了什么，保留了哪些术语与限定，怎样转述来源，怎样从材料推到判断。提炼成可复用原则，例如“先写对象和观点，再比较研究角度”“用具体动作或关系替代抽象赞词”。不要保存可识别原作者的大段范文到通用仓库。

同时辨别范文的弱点：文献数量与研究质量之间的跳跃、未经证明的受众效果、重复书目、过宽引页、来源观点与作者延伸混写。学习应包括纠正这些问题，而非复制其结论强度。

## 学习结果怎样进入写作
采用“观察到的特点—它的论证功能—本研究是否需要—具体采用方式”四项记录。比如，范文比较几个定义后建立分类，可以转化成“先解释概念分歧，再提出适合材料的分析尺度”；不必复制其概念、标题或原句。

引用形式单独落实。正文注码与文末书目序号可能是不同体系；有脚注文件不代表正文已存在可编辑脚注。最终使用哪种符号、编号方式与格式，由学校要求确定。
