# 隐私与发布规则

## 发布范围
本仓库只接收自行编写的通用方法、空白模板和与个人研究无关的示例。实际论文、题目、作者身份、导师学校信息、授权范文、摘录、截图、原始模型回执、本机路径、会话编号、数据库登录信息和迁移包，保存在独立私人项目。

## 从私人工作提炼方法
先写抽象原则，再检查是否还包含可识别研究对象、原作者或具体材料的细节。不要只替换姓名后复制原段落；不要把用户原句、独特题目、范文目录或长篇引文当作通用示例。示例应另行自拟并说明性质。

## 发布前
检查准备提交的文件清单、文件名与正文；检查Git作者姓名、邮箱、提交说明、历史和标签。截图、Office/PDF元数据、压缩包和JSON回执可能藏有身份或原文，默认不纳入。通用仓库从空历史初始化，不能把私人论文仓库直接复制后删除最新文件来冒充脱敏。

.gitignore仅是防误提交辅助，不会清除已经跟踪的文件或历史。每次使用明确路径暂存，检查暂存差异与内容，避免直接git add全部项目。账号名和仓库所有者是GitHub自身可见属性；不要声称在该平台实现完全匿名。

## 误提交时
立即停止分享，确认仓库可见性和泄露范围。删除当前文件不等于清除历史；历史重写、远端缓存、分叉与下载副本需要分别处理。涉及凭据时须撤销或轮换，不能仅删文件。
