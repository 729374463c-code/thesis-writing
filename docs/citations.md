# 文献、观点与引注

## 来源选择
中文研究优先考虑与问题直接相关的权威原典、专著、CSSCI来源期刊、北大核心及必要的专业期刊。记录目录版本；CSSCI来源、扩展版和其他评价体系不能混称。外文来源优先正式同行评议版本和权威学术出版物。刊物等级不能替代相关性与内容核验。

## 阅读证据
分别记录原刊相关页、网页正文或作者版本、摘要题录、背景线索。版本和访问证据不等于文章质量；读到某页不等于全文核读。网页全文没有原刊页码时，不能用文章起止页冒充具体引页。

每条引用至少承担一项用途：概念界定、理论依据、历史事实、研究方法、观点争议、案例比较或反证。只与题目主题相近而不能支持对应句子的来源不进入正文。

## 引语与转述
直接引语核原句、上下文、版本与具体页码；转述保持原意并标注出处。区分来源作者的观点和本研究在此基础上的解释。经范文发现文献后应回查原始来源，未查原典时不能写成已直接阅读；必要的转引链明确标出。

## 引注验收
按学校规范确定正文注码、页下注或尾注、编号和文末书目体例。允许同一来源多处引用，但文末书目去重。分别统计去重来源数、引用位置数、直接引语数和真实脚注数，不能互相替代。正文与书目双向核对；删段或换来源时同步更新证据卡。
