# 完整工作流程

## 1. 收敛问题
先明确研究对象、一个具体问题、理论视角和现有材料。题目、大纲和方法须相互对应。不要先设定实验、调查或技术指标，再强迫材料配合。将事实、作者说明、推断和待验证设想分开记录。

阶段成果是一页研究问题卡：研究什么、为什么需要研究、凭什么回答、目前回答到哪一层。学校规范和作者最新要求优先于范文体例。

## 2. 读范文与做文献
范文用于学习组织方法，学术文献用于支持论点。二者不自动等同。依次拆解目录、段落功能、引文用途和版式，回查关键文献的原始来源。以“文献—观点—原文位置—拟用章节”建立证据卡，不按搜索结果数量衡量完成度。

## 3. 制作大纲
每章必须有一个独立问题、材料和阶段结论；相邻章节应推进分析。只在一节确有多个独立论点时增加下级标题。提交审核的大纲使用正式标题和简洁的研究方向描述；内部分工、字数安排、待办与争议另存。

## 4. 正式写作
每次写作使用已核证据卡与当前大纲。先解释具体概念，再分析材料关系，形成有证据支持的局部判断。避免将理论集中放在绪论，后文仅罗列案例；也不要为了引用而给每个段落平均分配文献。

## 5. 修订与审查
先查结构和论证，再改语句，最后检查引用与排版。语言清理后重新做事实复核。跨模型审查只传必要材料，记录审查者实际读到的范围；返回“完成”并不代表意见正确。

## 6. 交付与续接
保留一个明确的正文源文件，交付Word由该版本生成。记录日期、版本、修改原因、未解决事项和所需材料。正式稿与内部工作记录分开。跨电脑迁移须核对文件清单与版本；方法库不接收实际项目素材和迁移压缩包。
